# Digital Psychological Wellness System for College Students

A simple web app to help college students monitor their psychological wellness via daily mood and stress check-ins, and view helpful resources.

---

## Features

* User registration (username/email)
* Record daily check-ins (mood, stress level, notes)
* View your check-in history
* Browse helpful resources

---

## Technology

* **Backend:** Python Flask + SQLite
* **Frontend:** ReactJS
* **Database:** One-click DB initialization command
